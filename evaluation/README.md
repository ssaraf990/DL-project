# Evaluation Module

This module contains unified evaluation scripts and visualization functions to assess model performance across the 5 folds of ESC-50.

## Modules

- `metrics.py`: Computes key evaluation metrics including:
  - Accuracy
  - Precision (Macro & Weighted)
  - Recall (Macro & Weighted)
  - F1-Score (Macro & Weighted)
- `confusion_matrix.py`: Plots and saves normalized confusion matrix heatmaps.
